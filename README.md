# 🎤 MicCheck – Gig Tracker for Stage Anchors

A sleek, dark-themed, single-page app for college stage anchors to manage upcoming campus gigs.
No login, no backend, no external services. Everything is stored in your browser (`localStorage`).

## Features
- Add a gig with title, date, time and an optional co-anchor
- Toggle a gig between **Upcoming** and **Completed** by tapping its badge
- Edit a gig, with a review step to confirm or discard changes
- Delete a gig
- Duplicate protection: the same title, date, time and co-anchor can't be added twice
- Friendly empty state and a mobile-friendly layout

## Run it
Open `index.html` in any modern browser. No build step or dependencies.

## Files
- `index.html`: page structure
- `style.css`: theme and layout
- `script.js`: app logic and browser storage

## Host it free with GitHub Pages
